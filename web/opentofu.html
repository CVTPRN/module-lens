TRANSPARENT ANALYSIS

What does ModuleLens analyze?

The Python collector resolves public GitHub module tags to commits and parses declarations with an HCL/JSON parser. The browser builds reports from fixed snapshots. Analysis is rule-based and does not use AI.

What the comparison covers

  • Inputs: additions, removals, types, defaults, validation, sensitivity and nullable/ephemeral settings.
  • Outputs, provider requirements, CLI version constraints and internal module calls.
  • Resource declarations, moved/removed/import blocks and original migration documents.
  • Renames require an explicit documented mapping, with the old input removed and the new input added.

Terraform and OpenTofu

Terraform analysis uses .tf and .tf.json files. For OpenTofu, matching .tofu and .tofu.json files take precedence. This models file selection; it does not certify CLI compatibility.

What the report cannot determine

User configuration, state, provider APIs and HCL expressions are not evaluated. We do not run plan, apply or downloaded code. Type compatibility, conditional resources and actual infrastructure impact require manual review. Select local submodules separately; transitive dependencies are not evaluated.

Data coverage

For each module, the collector indexes recent stable releases, key releases from the last three available major versions and configured anchor versions. It examines up to 400 tags. Only processed versions appear in the list. Intermediate releases are not fully analyzed; changelogs and documentation from indexed intermediate versions supplement the comparison.

Extending the catalog

Entries in modules.json specify the repository and optional anchors versions. Run python -m collector.collect to refresh the data. This also runs in GitHub Actions; the public website does not require a token.

Confidence and limitations

Parser errors or unsupported blocks mark the analysis as incomplete. Missing migration guides or a result with no breaking changes found do not guarantee a trouble-free upgrade. The checklist is a browser-based reminder.
